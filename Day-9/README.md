# Day 9 Projects

This folder contains two small projects built with React, TypeScript, Vite, and Tailwind CSS.

## Task Management Board (Kanban)

A Kanban board for organizing tasks through **To do**, **In progress**, **Review**, and **Done**. Tasks can be created, edited, searched, filtered, and moved between columns.

[Open the Task Management Board project](./Task%20Management%20Board%20(Kanban)/) · [Project README](./Task%20Management%20Board%20(Kanban)/README.md)

## Notes APP

A notes workspace for creating and editing notes, organizing them into folders, searching, and marking favorites. Changes are saved in the browser.
