# Day 3: React Practice Projects 🚀

Welcome to Day 3 of my React practice journey! This folder contains two hands-on projects built with **React 19**, **TypeScript**, **Vite**, and **CSS Modules**.

---

## 📂 Projects Overview

### 1. [📝 Todo App](./src)
A clean, modular task manager featuring task creation, inline editing, status toggles, and dynamic filtering (**All**, **Active**, **Completed**) built using composed components and CSS Modules.

- **Location**: Root directory (`./`)
- **Key Concepts**: Component composition, controlled inputs, state filtering with `useMemo`.

---

### 2. [🧠 Quiz App](./Quiz%20App)
An interactive quiz application covering core React fundamentals with keyboard shortcuts (`A`–`D`, `1`–`4`, `Enter`), instant feedback with explanations, question shuffling, and a detailed score review screen.

- **Location**: [`./Quiz App`](./Quiz%20App)
- **Detailed Documentation**: See the [Quiz App README](./Quiz%20App/README.md)
- **Key Concepts**: Multi-stage state machine, keyboard event handling, animations, dynamic progress segments.

---

## 🛠️ Tech Stack

- **React 19**
- **TypeScript**
- **Vite**
- **CSS Modules**

---

## ⚡ Quick Start

Each project is independent and can be run with standard Vite scripts:

```bash
# To run the Todo App:
npm install
npm run dev

# To run the Quiz App:
cd "Quiz App"
npm install
npm run dev
```
